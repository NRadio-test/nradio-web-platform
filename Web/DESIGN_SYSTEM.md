# 鲲鹏知识光球与知识星图设计系统

本文件只约束 `/knowledge/` 的光球入口及 `/knowledge/galaxy/` 的星图体验；知识库既有检索卡片、管理页和站点其他页面仍以现有 `site.css` 为准。它记录 2026-09-16 仓库中的实现，不把目标、参考图或尚未测量的性能写成已经验证的结果。

## 1. 项目概览

- 产品：NRadio-Bot 鲲鹏无限公开资料知识库。
- 页面类型与表面：知识检索内容页 + 可交互的全屏产品视图；对应 Content/Editorial/Docs 与 App/Product UI 的混合表面，属于既有页面的局部改进。
- 平台与栈：响应式 Web，原生 HTML、CSS、ES module JavaScript 和 Canvas 2D 三维投影；无 UI、WebGL 或动画库。
- 用户：需要检索、核对来源与阅读完整网站知识块的访客。
- 主要目标：把知识库右侧旧头像/统计区域改为可进入的真实数据预览，再在全屏星图中探索、检索并追溯同一批知识块。

## 2. 品牌方向

- 风格与语气：原知识库仍是站点深蓝、青色和金色；新观测窗与全屏星图改用真实天文摄影、近黑幕布、偏暖白文字和低饱和星光，呈现 NASA/ESA 观测档案而非 LED 球或 CSS 假星云。中文文案直述操作与资料边界。
- 单一概念：**一座可以核对资料的天文观测台**——首页以 NASA M101 影像承托同一知识球的细小星点，进入全屏后可切换 M101、NGC 1333 与银河中心三张官方底片；真实 InfoID 的光点在照片上方独立投影、缓转，选中后才出现有依据的有限关联线和完整 DOM 正文。照片负责空间氛围，资料层负责可操作性，二者不互相冒充。
- 遮住品牌名后的概念检验：单张宇宙照片或细点群仍可能像普通太空海报；实际 InfoID 一点一块、同步的标签/来源坐标、可切换且具署名的官方底片、来源核对入口是此体验的辨识点。旧版的蓝青霓虹与渐变星云容易把星点读成装饰 LED，已在新舞台改成中性摄影底片和低饱和点光。外观是否达标仍以重绘后的最终浏览器截图为准。
- 参考来源：用户四张附图提供空间与点群方向；实际底片分别来自 [NASA M101](https://science.nasa.gov/image-detail/m101/)、[ESA/Hubble NGC 1333](https://esahubble.org/images/heic2304a/) 和 [NASA/Hubble 银河中心](https://science.nasa.gov/image-detail/hubbleimage1p1611a1r/)。页面保留各底片署名与官方档案链接；不把用户参考图直接作为站点背景。
- 文案规则：统一说“网站知识块”，不暗示它与 AstrBot 后续可能产生的内部向量分块一一相同；“探索知识星图”“返回知识库”“显示全部”“重置视角”分别对应不同动作。加载、回退、无匹配和失败均在页面中给出文字状态，不用假数据填空。

## 3. 色彩系统

观测页在 `.galaxy-app` 内覆盖部分站点变量，首页的 M101 预览也采用相同暖中性调。下表只记录这两处新体验的主要色值；旧知识卡片仍用原 `site.css` 深蓝/青色。比例是视觉角色，不是逐像素测量。

| 角色 | 实际颜色 | 使用 |
|---|---|---|
| 60% 摄影场域 | `#0b1219` 全屏底色、`#0b1015` 首页预览底 + 三张站内 JPEG | 照片未就绪时的深蓝黑底、默认 M101 影像和可选观测底片 |
| 30% 浮层与深度 | `#10151a`、`#31363a`、`rgba(11,15,19,.89)`、`rgba(9,12,15,.94)` | 搜索面板、详情、控件与 tooltip |
| 10% 焦点/关系 | `#d9b880`、同来源线 `rgb(236,198,151)`、共享标签线 `rgb(186,211,226)` | 暖金焦点、文字外链、少量有依据的细线 |
| 主文字 | `#f3efe7` | 标题、完整正文、按钮与观测窗说明 |
| 次文字 | `#d0c8bb` | 元数据、状态、影像署名与辅助说明 |
| 分隔 | `rgba(243,239,231,.19)` | 原生输入/控件边与详情内部规则 |

影像层以 `background-size: cover` 铺满视口，舞台叠加横向深蓝黑 `rgba(6,11,17,.41–.56)` 和上下暗角，不使用 CSS 渐变伪造银河云。银河中心的原始照片因恒星极密，单独降至 `brightness(.72) saturate(.9)`；底片以 `opacity` 交叉淡入。照片上的静态星点/旋转微光另由 Canvas 绘制。知识点主体色按来源给极轻的暖/冷中性变化，成员上传按首标签稳定 hash 取六组低饱和色；官方为近中性淡青白、抖音为浅冷白，并非青蓝金 LED 编码。连线的暖色仅指同一来源 URL，冷色仅指至少两个共享标签，DOM 图例写出依据。入场过渡也使用站内 M101 与近黑幕布 `#0b1219`；旧知识卡片仍保留深蓝站点色，不能称为已全站统一。

## 4. 字体系统

- 实际字体：站点 CSS 的 `Inter, ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；InfoID 用系统等宽字体。没有新下载字体或字号 token 层，不能称为已统一的全站字阶。
- 选择依据：延续既有知识页的中英双语清晰度，资料正文以安静的无衬线字体为主，InfoID 用等宽字形强调可核对性。
- 当前页面字阶映射：知识页 `h1` 为 `clamp(3rem,4.4vw,4.4rem)`，窄屏 `clamp(1.85rem,9.5vw,4.2rem)`；星图 `h1` 为 `clamp(1.16rem,1.5vw,1.44rem)`；详情标题为 `clamp(1.28rem,2vw,1.6rem)`；详情正文 `1rem/1.75`；筛选输入 `.95rem`；控件、状态与元数据约 `.72–.9rem`。按钮文字以各控件实值为准，没有虚构共用的 `button` 字阶。
- 阅读规则：完整正文在可滚动 DOM 面板显示，`white-space: pre-wrap` 保留段落；正文不烘焙进 Canvas。星图详情正文达到 16px。旧知识卡片 `.knowledge-text` 为 `.88rem`，旧结果摘要等也低于技能的 16px 正文质量线：这次未改其布局与排版，不应把该既有缺口记成已通过。后续若统一字阶，先修这类实值。

## 5. 布局系统

- 知识首页：站点 `.shell` 最大宽 `1180px`、桌面边距 `24px`、窄屏边距 `14px`；`knowledge-hero` 左内容/右 `420px` 观测窗，`72px` 间距。右侧预览高 `285px`，充满原右侧视觉区；下面保持原搜索、标签、结果数、知识卡片、边界说明与 footer 的顺序。
- 首页的左右布局是用户指定的既有信息结构，不是新做的 50/50 图卡营销 hero；右侧不再是头像/两块硬编码统计，而是可点击的实时观测窗。`980px` 以下改为单列，预览最多 `560px`；`700px` 以下高 `240px`，卡片单列。是否在约 700/800px 高的真实视口完全容纳，应以页面截图而非 CSS 推断。
- 全屏：`.galaxy-app` 固定 `100svh` 舞台；照片层与独立 Canvas 都占全视口，顶部是返回、标题、实际点数，左侧是搜索/标签/观测底片选择/图例，左下是可展开的照片署名，右下是缩放/重置，桌面详情从右侧浮出。它不是长文档页，也无水平卡片轨道、转化 CTA 或营销 footer。
- `880px` 以下左面板宽从 `336px` 缩至 `294px`；`700px` 以下搜索/标签/底片选择面板贴近顶部且限高 `min(34svh,280px)`，详情改为底部面板 `min(53svh,480px)`。移动选中时光点聚焦中心上移约视口高度 20%，筛选浮层、影像署名和缩放/重置浮控临时隐藏，避免挡住光点；关闭详情后恢复。桌面 `max-height:610px` 时缩小上下边距。触屏提示替换鼠标提示。
- 内容流：搜索结果可滚动，详情全文可独立滚动；底部详情打开时临时隐藏移动端筛选与视角浮控，释放上半舞台。返回入口始终留在顶部，首页搜索和卡片仍在原页面流中。

## 6. 组件系统

- 基础：原生 `<a>`、`<button>`、`<input type="search">`、`<select>`、`<aside>` 加 CSS；知识点绘制模块独立于页面数据/控制模块，无第三方组件或图表库。
- 观测窗：`#galaxy-preview` 是整块链接，Canvas `aria-hidden` 且不截获点击；M101 影像、照片署名、动作与 Enter 提示、加载状态角标都在链接内。焦点由整块链接承接。
- 星图舞台：`#galaxy-canvas` 处理投影、前后遮挡与真实点命中；装饰粒子独立绘制，不参与命中；DOM 承载全部标题、搜索、图例、状态与详情。
- 控件：返回链接、44px 最小高度的缩放/重置按钮、原生搜索输入、标签及底片下拉、结果按钮、可展开的影像署名 `<details>`、详情关闭按钮。没有 disabled 状态的常规流程；若以后加入异步提交，需补足禁用原因与工作中反馈。
- 内容：知识首页保留既有卡片与筛选按钮；星图的结果按钮显示标题和 InfoID，详情逐项显示 InfoID、标题、完整 `text`、来源类型、资料核对日期、可信度、标签、关联说明和安全的 HTTP(S) 原始来源链接（缺失则给文字解释）。
- 状态组件：`aria-live` 点数/预览状态/匹配数、`role="status"` 加载或警告文字、无匹配结果文案；API 和静态数据都失败时显示错误，不留空白星图面板。

## 7. 卡片与浮层处理

- 观测窗半径 `8px`，M101 照片+暗角+浅色细边和近黑阴影，hover 上浮 `3px`，pressed 缩至 `.993`；它是可进入的观测窗，不再嵌套两块统计卡。
- 星图筛选浮层半径 `8px`、背景 `rgba(11,15,19,.89)`、`blur(8px)` 和近黑阴影；模糊只用于照片上的功能面板。详情半径 `8px`、底色 `rgba(11,15,19,.97)`，移动端仍为 `8px` 底部面板，承载长正文。
- 输入、控件、署名与详情使用浅色低透明描边提升照片前的可辨识性；不是旧版的圆润玻璃卡。原知识卡片本身仍是旧版带细边的视觉样式，本文不宣称全站改成统一观测台外观。

## 8. 图标系统

这两页没有图标库。使用现有文字/字符：`⌕` 搜索、`←` 返回、`＋/－` 缩放、`↗` 进入或外链、`×` 关闭；图例用 CSS 小圆点与短线。只有符号的缩放按钮有 `aria-label`；入口和关闭也有可读标签。未来新增图标应维持同一轻量文本/站点原生风格，不混用另一个默认图标库。

## 9. 图片与资产规则

- 既有品牌 logo 是站内 `/assets/nradio-logo.png`；旧鹏仔图片仍可作 favicon，但不再出现在知识首页右侧的预览区。
- 用户四张参考图只用于点群与空间方向，没有直接作为页面资产；没有新增 AI 图片、远程纹理或第三方 CDN。
- 三张实际观测底片均是**本站自托管** JPEG：默认/首页 [M101 NASA 官方合成影像](https://science.nasa.gov/image-detail/m101/) 为 `/assets/nasa-m101-observatory.jpg`（本地 `2600×2032`、`1,614,746` 字节，官方档案署名含 Hubble、CFHT、NOAO 贡献）；[NGC 1333 ESA/Hubble](https://esahubble.org/images/heic2304a/) 为 `/assets/esa-perseus-ngc1333.jpg`（本地 `2624×4000`、`2,473,696` 字节，署名 NASA、ESA、STScI）；[NASA/Hubble 银河中心](https://science.nasa.gov/image-detail/hubbleimage1p1611a1r/) 为 `/assets/nasa-milkyway-core.jpg`（本地 `1200×1037`、`621,504` 字节）。这三个尺寸/字节数来自本机文件检查；没有把背景照片的亮星称为资料光点。
- 首页固定 M101；全屏默认只让 M101 进入 CSS 背景，选择另两张底片时由本站 JS `Image.decode()` 成功后才标记已加载并切换。失败保留原底片，选择值退回；切换底片同时更新 `<details>` 中的具体署名、处理说明和官方原始档案链接。照片在 Canvas 后，`aria-hidden`/`pointer-events:none`，只作场景而不参加知识点击。
- 资料光点、近景装饰粒子与少量细线由本站 ES module 的 Canvas 2D 绘制；`3600` 个确定性球内微光和 `1650` 个固定远景星点由数据版本种子生成，首页预览/移动端以 stride 抽样。远景层在 resize 时预绘到离屏 Canvas，装饰点不进入 `projected` 的知识命中表，也不计入知识块数。当前同步 JSON 有 `277` 个唯一 InfoID、`277` 份有效坐标，页面计数仍取实际加载后的数据而非把 277 写死。
- 预览 Canvas 以父链接固定高度预留布局；全屏 Canvas 全视口。品牌 logo 的尺寸由旧 CSS 设定，但 HTML 未写 `width`/`height`；若做全站 CLS 治理应补上源尺寸，不能假称已优化。

## 10. 动效与交互系统

- 体验层级：用户明确要求空间光球。**Canvas 2D experiential exception**：不用 Three.js/WebGL、GLSL、物理引擎、Lottie、Spline 或平滑滚动；转场采用本站原生 Web Animations API 的 transform/opacity，而非大型路由动画库。DOM 内容先存在；绘制失败时仍可用首页检索、全屏搜索/标签/结果读取知识。
- 跨页入场：首页整块原生链接在普通点击或 Enter 时截取预览球面中央，以 `620ms`、`cubic-bezier(.22,1,.36,1)` 与约 2.5% 的柔和回弹，沿页面中心放大到 `92vmin`；带自托管 M101 背景的圆形快照跨过近黑幕布 `#0b1219`。预览 Canvas 快照在摄影球内仅 `.28` opacity，避免放大时出现模糊白灯珠。导航后 `sessionStorage` 短时（5 秒）携带快照及预览 yaw/pitch，全屏首帧继承方位，真实 Canvas 用约 `480ms` 透明度交叉淡入，浮控以约 `390ms` 轻微位移入场。目标 Canvas **不做 CSS scale**，因为投影尺寸与命中必须基于原生全视口边界。Esc 可取消离场并清理快照；修改键/新标签保持原生链接行为；绘图未就绪、页面不可见、API 不支持或系统减少动态效果时直接进入页面。
- 光球：同一 `GalaxyScene` 投影及同步坐标供预览和全屏使用。自动偏航周期常量 `300_000ms`，每帧用 `TAU × 实际 delta / 周期` 加角度；全屏在拖拽、悬停、选中、视角过渡与最近操作后的 `1800ms` 内暂停，再以 `1800ms` ramp 恢复；定位/重置过渡 `680ms`。预览只展示、旋转与整块进入，不在小图点选详情。
- 坐标与数据：同步脚本的第 1 版坐标算法用 SHA-256 为标签/来源 URL 生成方向，为 InfoID 加入稳定扰动和半径；标签权重依次为 `3.2/1.15/.85/.65/.5`，来源权重 `.9`，InfoID 扰动 `.27`，半径 `.55–.98`。因此相近标签/来源倾向同一区域，同一 InfoID 在同版数据的两个页面和刷新间保持位置。先取 `/api/knowledge`，失败回退 `/data/knowledge.json`；坐标版本或元数据条目数无效的来源不采用，API/静态版本不一致时以 API 数据及其坐标为准；运行时重复/缺失 InfoID 有警告并跳过，缺坐标用该 ID 的稳定临时位置。
- 指针/触屏：滚轮按指针位置缩放、拖拽转动、单指旋转、双指按中点缩放。纵向屏幕拖拽将 `dy` 反号传给三维俯仰，确保往下拖时正面球面跟随向下，而不是反向。距离限制 `2.15–5.5`，默认 `3.35`；选中移动到 `2.65` 并转到前侧。Canvas 命中只看前侧、符合过滤条件的真实知识点，重叠时比较距离及前侧深度；点选前重绘确保拖动/滚轮后坐标及时更新。
- 搜索/筛选：匹配 InfoID、标题、完整正文、标签；匹配点高亮、其余淡化。结果按钮可用键盘选择并转向对应前侧点；原生标签 select、显示全部及视角重置是独立操作。重置视角同时结束当前选中，避免所选光点旋至背面时仍保持详情。深链接 `?id=<InfoID>` 打开知识块，关闭删除参数；Esc 关闭并把焦点移回视角控件。
- 状态：默认/hover/`:focus-visible`/pressed 在入口、主要控件和结果按钮均有明确样式；过滤按钮和原生 select 有 hover 与 active。底片切换先在本地解码，失败保持原影像；成功使用本站静态知识数据只在状态行普通标注，版本差异、空匹配及两种知识来源都加载失败另有文字输出。尚无需要 toast 的写操作或提交表单，不虚构成功 toast、表单校验、横向轮播。
- 停机：页面不可见时取消动画；首页预览离开视口时经 IntersectionObserver 暂停；`prefers-reduced-motion` 时无连续动画、跨页入场，交互转向即刻绘制。CSS 同时收短过渡。LCP `<2.5s`、CLS `<0.1`、INP `<200ms` 是后续 Core Web Vitals 实测目标，不能由帧率推断已达成。
- 星点尺度：真正网站知识点的未选中光学核心由投影深度调整，在全屏约 `.48–4.1px`，小点用中性微光与少量稀疏衍射线；前侧匹配点另有不足 `1px` 的暗色光学边界，将资料点与照片自身恒星区分，不增加点击目标。不可见的命中半径单独保持 `7–16px` 以容纳指针操作。预览最大核心约 `3.25px`，但不点选；远景微光约 `.34–1.03px`，球内微光基础大小约 `.22–.86px`。选择/悬停时增加可辨认的细环，不把所有点变成等亮霓虹。照片亮星与上述装饰微光都没有知识命中目标。
- 现有轻量化实现：全屏无需 3D 库；首页加载知识后动态导入绘图模块；`3600` 个确定性球内微光在首页和手机按 stride 抽样，`1650` 个远景星点在 resize 时预绘为离屏图层而非逐帧重画；空闲绘制间隔约 `30ms`，拖拽、定位及近期操作约 `16ms`，实际自动旋转角度始终按经过时间计算；预览 DPR 上限 `2`、全屏上限 `1.75`。照片切换先本地解码再淡入，非默认照片不作为初始 CSS 背景请求。M101 JPEG 约 `1.61MB` 且位于两个页面的首屏，需实际检验其 LCP/网络影响；NGC 1333 约 `2.47MB`，仅在选择时加载。ResizeObserver 只在尺寸变化时重设画布/远景缓存；本次资源与 ES modules 都从本站加载，符合不调用第三方脚本/图像的 CSP 意图。线上缓存/CDN 与 Core Web Vitals 尚未验证。
- 2026-09-16 本机系统 Chrome/CDP（桌面 `1440×900`、手机视口 `390×844`）实测全屏空闲 `3.17s` 内约 `96` 次 draw，即 `30Hz` 目标节流；桌面 draw 平均 `3.20ms`、p95 `4.0ms`、最大 `4.7ms`，手机平均 `2.06ms`、p95 `3.0ms`、最大 `5.6ms`。这只是本机 headless Chrome 画布耗时，不等于手机实体设备、iOS Safari、LCP/INP 或线上表现。

## 11. 可访问性规则

- 已计算的观测页主要文字对比度（WCAG sRGB 公式，在不透明色值上计算）：`#f3efe7/#0b1015 = 16.66:1`、`#d0c8bb/#0b1015 = 11.52:1`、暖色焦点 `#d9b880/#0b1015 = 10.12:1`；即使对更亮的浮层候选底 `#31363a`，主文字也有 `10.65:1`、次文字 `7.36:1`。这些计算支持浮层文字配色，但照片本身亮度随位置变化、浮层半透明叠加和旧知识页的所有文字对尚未逐像素或逐项审计，不能据此宣称整页/全站 AA 全过。
- 整块预览是可 Tab 到达的 `<a>`，Enter 使用浏览器原生激活；全屏有跳到搜索的链接、Canvas 的可读标签与 fallback 文本、键盘 `+/-/0` 缩放/重置及方向键转动；`/`、`⌘/Ctrl+K` 可聚焦搜索。直接逐点的键盘遍历未实现，键盘选点通过可读的搜索结果按钮完成。
- 悬停 tooltip 有 `role="tooltip"`，在视口边缘计算翻转/夹取，标题预览不会跑出边界；详情是非模态 `<aside>` 而非 dialog，不使用不必要的焦点陷阱。详情内容和外链保持 DOM 可读，Esc/关闭按钮可结束选择。
- 语义和系统适应：`main`、`header`、`aside`、真实 button/link/input/select、`aria-live` 文字状态、`:focus-visible`、移动安全区、`prefers-reduced-motion`、`forced-colors` 控件描边。三张照片都是 `aria-hidden` 且不可点击；可展开署名使用原生 `<details>` 和可聚焦官方链接。知识点/关系有文字图例，不只靠暖冷色区分。
- 已知保留问题：旧知识卡片的小号文字及旧站点部分低对比度字面色仍需单独审计；200% 缩放、屏幕阅读器和高对比度的真实浏览器验收应在完成报告中另列，不凭 CSS 声称通过。

## 12. 抗模板化检查

- 新观测体验的核心色是第 3 节列出的近黑、暖白、灰米与少量暖冷关系色；照片色相来自官方影像而非用 CSS 另画一套假星云。历史 `site.css` 仍有旧深蓝/青金字面色，本文件不是全站色值清理声明。
- 例外由用户需求决定：保留知识首页原左右结构；使用沉浸式 Canvas 2D 而非默认 WebGL 库；保持旧卡片、搜索与页脚行为。旧站点的渐变标题文字、边框卡片和小于 16px 的卡片正文是既有范围，不应作为这次光球设计“已通过”或偷偷重构的依据。
- 检验重点：当前数据 `277` 个唯一 InfoID/有效坐标，各对应一个实际可点光点；照片及 `3600+1650` 个确定性装饰星点不冒充资料；选中才绘制最多九条同来源或共享至少两标签的线；无虚构统计、通用 AI sparkle 徽章、远程视觉脚本或静态效果图。桌面与手机尺寸的外观剪裁已经由当前版本 Chrome 截图核对；Core Web Vitals 仍需另行实测。
- 本轮摄影重绘在系统 Chrome 的桌面和手机尺寸下已核验：三底片加载并稳态显示、搜索/标签/清除、缩放拖拽后两个实点 InfoID 与全文逐字匹配、装饰点不选中、Esc/按钮关闭、深链接、返回及跨页摄影入场；两尺寸无 JS exception 或 console error。截图和可复核 CDP 报告留于 `/private/tmp/nradio-photographic-qa/`，设计核对见仓库根部 `design-qa.md`。这不能推断线上发布、iOS Safari、屏幕阅读器或真实用户设备表现。

## 13. 后续页面约束

以后修改这两处知识页，应复用“自托管且有署名的观测底片 + 独立 DOM/Canvas 知识层”的分层、暖中性浮控、`GalaxyScene` 的一致坐标和原生交互控件。新增视觉点必须明确属于网站知识块还是纯装饰；新增关联线必须有可读依据，不以摄影亮星或视觉密度替代资料可信度。其他 NRadio 页面不因本局部文档自动改风格。

## 14. 更新政策

颜色、字阶、响应式尺寸、光球投影/速度、来源色、关联规则或可访问交互变化时，应同时更新相应 CSS/JS 和本文件。浏览器测量、线上部署或 CSP 验证完成后再写实测结果；未经验证的目标继续标成目标，不改写为成功状态。
