# 鲲鹏知识光球：黑场点群设计与资料边界

本文只描述 `/knowledge/` 首页预览和 `/knowledge/galaxy/` 全屏页。旧知识卡片、搜索和站点其他页面保持现有设计。2026-09-16 的这版视觉以用户提供的黑底密集点群截图为形态参考，不把 NASA 照片贴为背景，也不给访客“选择底片”的控件。

## 设计意图

黑色是主体，细小的暖白/冷白星点构成一个有厚度的知识云：核心稍密、稍暖，外围稀疏、略冷，暗处仍留余量。亮度和尺寸连续随三维深度变化；不是等尺寸、等亮度的霓虹 LED。核心暖光由当前投影微粒在四分之一分辨率画布中累积曝光，再在锐利点群下合成；因此光随转动和实际密度变化，不是贴图或固定中心光斑。首页右侧是一整块可聚焦链接，只负责展示和进入；全屏舞台才负责浏览、筛选、点选与阅读。进入时跨页放大的是首页 Canvas 点群快照，抵达后淡入同数据、同坐标的全屏 Canvas。

## 资料粒度与视觉分层

| 层 | 来源与作用 | 可否点选 |
|---|---|---|
| 知识亮星 | 实际加载的一个唯一 InfoID 对应一个网站知识块；标题、完整正文和来源在 DOM 详情中读取 | 是，仅当前可见前侧、符合筛选的点 |
| 附着微光 | 以 InfoID 为随机种子，在其真实坐标旁产生更细、更暗的颗粒；搜索/筛选时跟随对应知识块淡化 | 否 |
| 球内星尘、少量光学星芒与远景 | 稳定随机的空间质感，前后投影并按深度描绘；少量星芒只围绕装饰颗粒、不连接知识点；远景独立缓存 | 否 |
| 关系线 | 只在选中知识块时，最多九条；相同来源 URL 或至少共享两个标签，暖/冷色分别说明依据 | 不是独立知识块 |

装饰层增加视觉密度，不增加“知识块”点数；图例和点数文字明确这一点。装饰颗粒随数据量增加，但逐条颗粒数自适应并设总量上限，避免未来知识库扩大时绘制成本线性失控。少量短光学芒线是装饰星的衍射效果，不表示知识关系；关系线不在空闲时遍布全场，以免暗示没有资料依据的关联。目前页面展示的是网站知识块，不保证与 AstrBot 导入后可能再次切分的内部向量块逐一相同。

## 数据与位置

首页和全屏都先读 `/api/knowledge`，失败回退 `/data/knowledge.json`，并共用 `GalaxyScene`。坐标由 `Web/scripts/galaxy-coordinates.mjs` 接入现有同步流程：标签与来源 URL 给主题方向，InfoID 给确定性扰动与半径。相同 InfoID 在刷新和两页面间稳定；坐标算法版本与数据版本在载入时核对。同步拒绝重复或必填字段缺失条目；浏览器遇到缺坐标、重复或版本差异会告警、跳过或用稳定临时坐标，不悄悄显示假的总数。

搜索覆盖 InfoID、标题、完整正文和标签；筛选/重置仅改变匹配和视角，不重新散布点位。匹配亮星保留、其余淡化；选结果转到前侧并打开可滚动详情。点击命中只使用真实知识点的三维投影、前侧深度和可见匹配状态；装饰星尘从不进入命中列表。视觉核心很小，隐形指针命中半径较大，以兼顾点状美感和缩放/旋转后的操作精度。

## 色彩、控件与排版

- 舞台是近黑 `#020408`，悬浮控件沿用深蓝黑；知识核心用中性白、浅冷白和少量暖白，选中与来源关联才强调金色。旧知识页的青金品牌色仍留在正文与卡片中。
- 全屏保留返回、搜索、标签、显示全部、视角缩放/重置和操作提示。桌面详情在右侧，移动端在底部；来源 HTTP(S) 链接、InfoID、核对日期、可信度、标签和完整 `text` 都是可读 DOM，不烘焙到 Canvas。
- 字体继承站点现有系统无衬线组合（Inter、Apple/System、Segoe UI、PingFang 等），InfoID 使用等宽字。详情正文 16px、`line-height: 1.75`；原知识卡片原有小字不在本次重绘范围内。
- 入口使用真实 `<a>` 并可 Tab/Enter。全屏支持键盘搜索结果选择、`+/-/0` 缩放/重置、Esc 关闭、`?id=<InfoID>` 深链接；触屏单指旋转/双指缩放，鼠标滚轮按指针缩放。控件、提示和详情遵循移动安全区与可滚动区域。

## 动效、性能与验证边界

空闲偏航按实际时间累积，目标每 `300_000ms` 一圈，不依赖帧率；拖拽、缩放、悬停、选中或定位时暂停，交互结束后逐渐恢复。页面不可见、预览离开视口时停止持续绘制；`prefers-reduced-motion` 禁用持续旋转和跨页放大。跨页动画只对快照使用 transform/opacity；全屏真实 Canvas 不做 CSS scale，避免投影坐标和命中偏离。Canvas DPR 和空闲/交互绘制间隔设上限，远景星点缓存于离屏图层。脚本、样式与资源均从本站加载，适配既有 CSP；本地 Python 静态服务器本身不施加生产 CSP 头，不能据此宣称线上已验证。

本地检查、桌面/手机视口实际浏览器结果与性能采样写在仓库根部 `design-qa.md`。目标是黑底细点群和数据真实可操作；实体手机、iOS Safari、生产缓存/CDN、Core Web Vitals 与线上发布须分别验证，不从本机截图推断。
